The single most important fact: the amplicon was sequenced at only 3 transfers {3,4,13}, and a breakpoint needs ≥ 4 timepoints. So on amplicon data the fourth parameter is not identifiable — all 186 trajectories collapse to a constant slope. Only the WGS design, which adds transfer T6, makes the breakpoint estimable at all — yielding 13 real increasing switches.

2What integration adds on well B4

B4 is the one culture measured by both assays — WGS sample concX_largeLib_SpeI.1.

Integration pools the two assays' reads per (transfer, variant) on B4. The amplicon deepens T3 / T4 / T13 from ~190 to ~10,000 reads, while WGS supplies the T6 point the amplicon never sampled — and it is precisely T6 that makes B4 breakpoint-testable. The result is more coverage and a resolvable breakpoint the shallow WGS depth alone missed.

3It re-estimates, it doesn't distort

Where do the fused rates land — on the deep amplicon, or the shallow WGS?

On B4's shared variants the single-slope rate does move, and interpretably. The integrated rates correlate r = 0.94 with the deep amplicon (median |Δ| 0.074/cycle, n 82) but only r = 0.67 with the shallow WGS-B4 estimate (median |Δ| 0.180/cycle, n 24). Because the fused frequencies are dominated by the amplicon's ~50× greater depth, integration effectively replaces WGS-B4's shot-noise-limited rates with amplicon-precision ones — variance reduction on the one shallow culture, converging on the higher-confidence assay.

Contrast with the global 1-parameter joint fit (s13d): there the amplicon only tightened B4's standard error without shifting its rate, because B4 was one of eleven wells sharing one global rate. This model is per-culture — B4's rate comes from B4's data alone — so replacing ~190-read points with ~10,000-read points genuinely re-estimates it.

4The adopted breakpoints

Barcode adopts 13; integrated adopts 14.

The ten non-B4 wells are WGS-only in both runs, so integration is purely additive: it keeps all 13 WGS switches and adds 1 new one on B4 (A81-B132). Acceleration keeps clustering in the same alleles the WGS run flagged — verA A81, A78; verB B26 — integration sharpens that story rather than rewriting it.

5Bottom line

Amplicon only

Deep but 3 transfers → the 4th parameter is not identifiable; every trajectory is constant. Use it for precise relative rates, not dynamics.

Barcode / WGS only

4 transfers over 11 wells → the breakpoint is identifiable; 13 variants show a real increasing switch. The workhorse regime for the 4-parameter model.

Integrated

WGS breadth + amplicon depth on B4 → strictly dominates both: most estimable, testable, and adopted, with B4 rates converging on the high-depth amplicon.

Honest caveat. Even in the WGS/integrated regimes, four transfers give the two-phase fit just one residual degree of freedom, so the in-sample fit gain is partly optimism — out-of-sample (LOOCV) the 4-var only clearly beats the 1-var when the elbow location is supplied. The model's value here is descriptive (exposing dip-then-rise dynamics a single slope averages away); integration's value is making that description possible and precise on B4.
